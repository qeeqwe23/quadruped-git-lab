# 四足机器狗跳上台阶：公式、程序与实测结果

这是一个可阅读、可复现的 MuJoCo 教学原型。它从静止开始，下蹲、蹬地、腾空收腿、落到台阶上，最后恢复站立。模型为自由浮动机身和 12 个主动关节；初始化后只输出关节力矩，不直接修改机身位置或速度，不给机身施加外部推进力，也没有隐藏的固定约束。

**结果与范围：默认 15 cm 台阶可以最终站稳，但落地有约 69.5° 的最大机身倾斜和约 567 N 的单脚接触峰值。它不是平顺、稳健的跳跃控制器。相同控制参数在本机 10 cm 案例通过、20 cm 案例失败；不能据此断言整个 10–15 cm 区间都可靠。**

这是针对已知台阶、已知模型调出的确定性样例，没有感知、状态估计、MPC、全身逆动力学、系统辨识或鲁棒性保证。不要将示例力矩直接发送到真实机器狗。

## 3. 单腿正运动学

定义脚相对髋外展轴的位置为 p=(x,y,z)。先在髋俯仰平面内计算：

\[
x=-l_1\sin q_1-l_2\sin(q_1+q_2)
\]

\[
s=-l_1\cos q_1-l_2\cos(q_1+q_2)
\]

然后考虑髋外展旋转和侧向偏移：

\[
y=d\cos q_0-s\sin q_0,\qquad
z=d\sin q_0+s\cos q_0.
\]

脚的世界坐标为：

\[
p_i^W=p_B^W+R_{WB}(h_i^B+p_i^B).
\]

其中 h 是髋外展轴在机身中的安装位置，R 把机身坐标转到世界坐标。代码的 `fk()` 是上述公式，`verify.py` 用独立的 MuJoCo 运动学进行对照。

## 4. 单腿逆运动学

首先恢复髋俯仰平面中的竖直分量，选择脚在髋下方的分支：

\[
s=-\sqrt{y^2+z^2-d^2}.
\]

因此必须满足 y²+z²>d²。髋外展角为：

\[
q_0=\operatorname{atan2}(z,y)-\operatorname{atan2}(s,d).
\]

将 q0 归一化至 [-π,π)，再用余弦定理：

\[
C=\frac{x^2+s^2-l_1^2-l_2^2}{2l_1l_2},\qquad q_2=-\arccos C.
\]

\[
q_1=\operatorname{atan2}(-x,-s)
-\operatorname{atan2}(l_2\sin q_2,l_1+l_2\cos q_2).
\]

可达条件为 |C|≤1。代码只容忍浮点级误差后裁剪；明显不可达时抛出异常，避免把不可达目标悄悄投影成另一个目标。几何可达还不等于满足实际关节限位、碰撞和力矩约束。

```python
def ik(p, side):
    x, y, z = np.asarray(p)
    d = side * .04
    yz2 = y*y + z*z - d*d
    if yz2 <= 0:
        raise ValueError('Foot too close to abduction axis')
    s = -np.sqrt(yz2)
    q0 = np.arctan2(z, y) - np.arctan2(s, d)
    q0 = (q0 + np.pi) % (2*np.pi) - np.pi
    C = (x*x + s*s - 2*L*L) / (2*L*L)
    if abs(C) > 1 + 1e-7:
        raise ValueError('Unreachable foot target')
    q2 = -np.arccos(np.clip(C, -1, 1))
    q1 = np.arctan2(-x, -s) - np.arctan2(L*np.sin(q2), L+L*np.cos(q2))
    return np.array([q0, q1, q2])
```

初始足端中心高度为 0.025 m，因此脚相对髋的 z 为 0.025−0.345=−0.32 m，而不是 −0.345 m。

## 5. 雅可比与力矩：为什么代码有负号

单腿雅可比定义为 J=∂p/∂q。对固定机身，有：

\[
\dot p=J\dot q.
\]

完整自由机身模型使用 3×18 的足端平移雅可比。程序调用 `mj_jacSite`，取该腿三个关节对应的列，得到世界坐标下的 3×3 关节雅可比 Jj。

如果 f 表示**地面对机器人**的接触力，简化静力平衡为：

\[
\tau+J_j^T f\approx0,
\qquad \tau\approx-J_j^T f.
\]

因此代码使用 `-J.T @ f`。常见的正号 `tau = J.T @ F` 往往定义 F 为机器人想对环境施加的力，或把它作为外力广义力映射；使用前必须先确定力的方向。

完整动力学是：

\[
M(q)\ddot q+h(q,\dot q)=S^T\tau+J_c^Tf.
\]

本例没有解这个完整方程来生成控制力矩，省略了显式的关节重力/惯性补偿，所以只能视为虚拟模型控制（VMC）近似。MuJoCo 物理仿真本身仍然模拟完整模型的动力学。

## 6. 起跳速度：抛物线只用于腾空质心

忽略空气阻力，腾空时整机质心 c 满足：

\[
c_x(t)=c_{x0}+v_{x0}t,\qquad
c_z(t)=c_{z0}+v_{z0}t-\tfrac12gt^2.
\]

设期望落地质心高度为 c_zL、水平距离为 Δx、飞行时间为 T：

\[
v_{x0}=\frac{\Delta x}{T},\qquad
v_{z0}=\frac{c_{zL}-c_{z0}}{T}+\frac12gT.
\]

若先选顶点高度 c_za：

\[
v_{z0}=\sqrt{2g(c_{za}-c_{z0})},
\qquad
T=\frac{v_{z0}+\sqrt{v_{z0}^2-2g(c_{zL}-c_{z0})}}{g}.
\]

加号根对应下降时到达目标高度。`plan_jump.py` 采用这一计算，自动检查输入正值。它不会检查足端、膝盖、机身是否越过障碍，因此只是运动规划的第一步。

本次仿真近似读数：离地质心高度 0.359 m、水平速度 1.419 m/s、竖直速度 2.087 m/s；约 0.36 s 后首次触地。代入可得 Δx≈0.511 m、Δz≈0.115 m，与记录接近。

注意：台阶高 0.15 m，但离地到首次触地的质心高度差并不必然是 0.15 m，因为两时刻腿部伸展和机身姿态不同。机身原点也不是整机质心；腾空收腿时两者相对位置会变。

**越过台阶还要检查脚和机身轨迹。** 本例台阶前沿是 0.30 m，足端球半径是 0.025 m；验收要求每只脚的中心 x>0.325 m，并检查顶面高度和非足端碰撞。

## 7. 下蹲轨迹与蹬地控制

下蹲采用五次平滑函数，u=(t−0.7)/0.6：

\[
s(u)=10u^3-15u^4+6u^5,\quad
z_d=0.345-0.10s(u).
\]

\[
\dot s=\frac{30u^2-60u^3+30u^4}{0.6},\quad
\ddot s=\frac{60u-180u^2+120u^3}{0.6^2}.
\]

所以该参考在起止时具有零速度、零加速度。

蹬地参考使用：

\[
a_{\rm ref}=\frac{[1.95,0,3.30]^T}{0.12},\quad
p_d=[0,0,0.245]^T+\tfrac12a_{\rm ref}t_p^2,\quad
v_d=a_{\rm ref}t_p.
\]

这里的 `[1.95,0,3.30]` 是生成蹬地加速度参考的参数，**不是实际达到的离地速度，也没有直接写入仿真速度**。接触提前消失、腿长限制、力矩饱和以及跟踪误差会让实际速度更低。

机身期望合力：

\[
F_d=m\{a_d+K_p(p_d-p_B)+K_d(v_d-v_B)+[0,0,g]^T\}.
\]

`p_B` 是机身原点，用它近似质心控制是本例的简化之一。起跳/站立阶段使用 Kp=diag(90,90,180)、Kd=diag(18,18,24)；落地后改为 diag(65,90,140) 与 diag(18,18,23)。Kp 的量纲为 s⁻²，Kd 为 s⁻¹。

忽略反馈项时，蹬地参考竖直合力约为：

\[
F_{z,ff}=9.16(9.81+3.30/0.12)\approx342\ \mathrm N.
\]

静止承重则只需要 mg≈89.9 N。跳跃对总支撑力的要求明显更高。上述值是规划请求，并非保证实际接触力相等。

## 8. 姿态反馈、接触力分配与摩擦限制

目标机身旋转为单位矩阵。用世界坐标表示的小角度/局部姿态误差：

\[
e_R=\tfrac12(R-R^T)^\vee,\quad
M_d=-K_Re_R-K_\omega\omega.
\]

程序中 KR=diag(100,100,60)，Kω=diag(12,12,8)。这种误差在大角度时不是线性角度误差，不能作为任意姿态恢复的保证。

令 ri 为脚相对机身原点的位置，`[r]×` 为叉乘矩阵：

\[
A=\begin{bmatrix}I&I&\cdots&I\\[r_1]_\times&[r_2]_\times&\cdots&[r_n]_\times\end{bmatrix},
\quad
w_d=\begin{bmatrix}F_d\\M_d\end{bmatrix}.
\]

程序使用带小正则的最小二乘分配：

\[
f=A^T(AA^T+10^{-5}I)^{-1}w_d.
\]

然后逐脚裁剪：

\[
0\le f_{iz}\le180\ \mathrm N,\qquad
\sqrt{f_{ix}^2+f_{iy}^2}\le0.75f_{iz}.
\]

这只是“先最小二乘，再裁剪”，**不是同时满足摩擦、单向接触、力矩限制的约束优化**。裁剪会破坏原来的合力/合力矩解；只有两只脚触地时，某些目标合力与合力矩本来就不能同时实现。这是落地不平顺的重要原因。

在关节力矩之外加低增益足端锚点反馈：

\[
\tau_i=-J_i^Tf_i+J_i^T\{K_f(p_{anchor,i}-p_i)-D_f\dot p_i\}.
\]

一般 Kf=100 N/m、Df=4 N·s/m；落地后未检测到接触的腿用 Kf=800 N/m，将脚拉向台面目标位置。控制器通过法向力大于 0.5 N 判断接触。

最终所有力矩裁剪到 ±45 N·m。**力矩限幅并不意味着接触冲击也被限制**；仿真约束在碰撞瞬间仍能产生很高的足端反力。结果中的 567 N 足端峰值没有被隐藏。

## 9. 腾空与落地状态机

| 状态 | 切换条件 | 控制 |
|---|---|---|
| settle | 0–0.7 s | 站立稳定 |
| crouch | 0.7–1.3 s | 五次曲线下蹲 |
| push | 1.3 s 起 | 合力/力矩控制蹬地 |
| flight | 蹬地超过 60 ms 且所有脚失去接触，或到 120 ms 上限 | 关节 PD 收腿/伸腿 |
| land | 飞行超过 120 ms 后首次检测到脚接触 | 捕获落脚锚点、降低机身增益、接触力分配 |
| stand | 首次触地后 350 ms | 同一落地反馈继续恢复站立 |

`stand` 是状态机标签，不代表那个瞬间就已经稳定；验收另行检查最后 0.5 s。腾空状态的超时保护也不证明已经真实离地，因此验收额外检查持续无接触区间。

腾空前 0.16 s，四条腿目标竖直长度为 0.20 m；随后前腿为 0.27 m、后腿为 0.33 m。目标 x 为髋前方 0.04 m，侧向偏移保持 ±0.04 m，用逆运动学转换为关节角。

\[
\tau=70(q_d-q)-2.5\dot q.
\]

目标关节速度取零。这是分段姿态目标，未采用连续落脚轨迹优化。腿在空中运动会通过角动量交换影响机身姿态，但不能在没有外力的情况下任意改变整机质心抛物线。

首次触地后，控制器将当前各脚位置的 z 改为台阶顶面加足端半径；机身水平目标取四脚当前 x 的平均值。它没有自动向更深的台面补步，因此后脚边缘余量很小。

## 10. 主循环和采样时序

```python
model = mujoco.MjModel.from_xml_string(model_xml(height=0.15))
data = mujoco.MjData(model)
# 初始化一次机身位姿和关节角；完整初始化见 jump.py。
mujoco.mj_forward(model, data)
controller = Controller(model, data, height=0.15)

for _ in range(4000):
    controller.compute()       # 最终只写 data.ctrl，12 个关节力矩
    mujoco.mj_step(model, data)
```

采样时序是本例重要的复现条件：`mj_step` 在最后积分，部分派生运动学数据（足端位置、姿态矩阵、雅可比）仍对应前一个积分采样，而 qpos/qvel 已更新。程序因此包含约 1 ms 的混合采样延迟，日志中的 COM 也是相应采样。此固定时序参与了调参；如果改成 `mj_forward`/`mj_step1` 同步反馈，必须重新整定，不能假设行为不变。工程实现应改为一致时间戳的数据管线并重新验证。

本例 COM 抛物线最大对照误差约 2.34 mm，包含时间离散与此采样效应，不能据此声称解析轨迹完全一致。

## 12. 下一步应该怎样改

第一优先是落地控制与时序：同步状态采样；连续规划四脚落地位置、速度和机身姿态；接触检测加入迟滞；根据实际触地组合分配可实现的力与力矩。

随后将力分配改成带约束的 QP，例如：

\[
\min_f\ \|W(Af-w_d)\|^2+\lambda\|f\|^2
\]

约束同时包含 fz≥0、摩擦锥近似和关节力矩限制；摆动脚强制 f=0。需要非线性圆锥时使用对应优化方法，而不是误称所有形式都是普通线性约束 QP。

再加入全身动力学：M qdd+h=Sᵀτ+Jᵀf，并对支撑脚施加 J qdd+Jdot qdot=0 等约束，统一协调机身、摆腿与关节力矩。连续跳跃、未知台阶或高动态运动还需要更完整的轨迹优化/MPC与感知系统。

这些是尚未实现的改进，不属于本例已完成能力。
